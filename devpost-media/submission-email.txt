Project: Pact: Payment Recovery for AI Agents on PayPal
Tagline: When an agent's payment fails, nobody's watching. Pact is.
Team: Devansh Bagaria, Divit Periwal, Aryan Singh

WHAT IT DOES
AI agents now make purchases for people. When an agent's payment is declined, no person sees the error, and existing recovery tools (dunning emails, SMS, "update your card" banners) all assume someone will. Pact fills that gap on PayPal:

- The merchant engine works out why the payment was declined and scores each recovery option by expected profit.
- It then replies with HTTP 402 Payment Required and a signed recovery offer, such as retrying with a different funding source.
- The buyer's agent accepts the offer only if it passes a 12-check guard against the limits the person set for it.
- Offers are signed with Ed25519 and tied to a single-use nonce, so a captured offer can't be replayed or redirected to another endpoint.
- A 10% live holdout measures how many recoveries Pact actually caused, not just declines that would have cleared anyway.

PayPal status: order create and capture are verified against the sandbox (log in scripts/spike/RESULTS.md). Saving payment methods (Vault v3) returned a 403 permission error on our sandbox app, so saved-method charges and test-card declines haven't run against the sandbox yet. The demo video runs in fixture mode and says so on screen.

AI TOOLS AND HOW THEY WERE USED
- OpenAI gpt-oss-120b, served by Groq through its OpenAI-compatible API, turns the buyer's plain-English instructions into a structured spending mandate and drafts recovery emails. Without an API key, both fall back to templates.
- Ask Pact, a read-only assistant, answers merchant questions such as "why did we drop this recovery?" from the decision ledger. It has an adapter for the PayPal Agent Toolkit's order lookup, which isn't installed in our builds yet.
- scikit-learn: a calibrated random forest predicts how likely each recovery option is to succeed.
- Thompson-sampling bandit: learns which recovery actions work for each kind of decline, within a profit floor.

No model can capture funds, change an amount or touch an authorization. Only the deterministic policy and the buyer's mandate can do that.
